## Como as imagens foram geradas
`.build/build.py` monta cada peça em HTML/CSS (capa real + fontes da marca embutidas) e renderiza
em PNG com o Chromium headless. Para regenerar: baixar as fontes em `.build/fonts.css` e rodar
`python3 .build/build.py`. (A pasta `.build/` é ignorada no git por conter artefatos grandes.)
